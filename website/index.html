Safety-first by design

The alpha keeps real third-party installation disabled. It is built to show risk, preserve auditability, and stop machine-wide changes from happening silently.

  • No silent install
  • No automatic UAC bypass
  • No automatic PATH modification
  • No automatic proxy modification
  • Local-first diagnostics
  • Approval-first execution

How it works

Every step keeps the user close to the decision before anything risky can happen.
