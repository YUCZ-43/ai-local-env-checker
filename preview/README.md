# Standalone Preview Files

This directory contains dependency-free review artifacts for `v0.9.0-alpha.1`.

## Files

- `software-ui-preview.html`: interactive desktop product direction with sidebar navigation, approval states, theme controls, and English / 简体中文 display controls.
- `website-preview.html`: single-file product website preview with the same glacier-blue and graphite visual system.

## Open locally

Double-click either HTML file, or open it from a browser. No build, package install, remote script, analytics, or external asset is required.

## Safety boundary

These files are visual and interaction previews only.

- Real third-party installation remains disabled.
- No installer command is executed.
- No UAC prompt is triggered or bypassed.
- PATH, proxy settings, and global environment variables are not modified.
- macOS and Linux packages are planned, not available.

The maintainable multi-file website source is under `website/`. The Windows alpha package, release notes, and download are published through the `v0.9.0-alpha.1` GitHub prerelease.
