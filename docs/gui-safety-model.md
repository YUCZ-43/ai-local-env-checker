# GUI Safety Model

The v0.6.0 desktop GUI is safe by default and preview-only.

## Disabled in v0.6.0

- Real installation
- System repair
- System or user PATH modification
- Global environment variable modification
- Global PowerShell execution policy changes
- UAC prompts or auto-elevation
- `plan run --confirm`
- MEDIUM, HIGH, or DANGEROUS plan execution
- Admin-required plan execution

## Allowed in v0.6.0

- List example install plans
- Read example install plans
- Show plan summary, commands, risk level, admin requirement, and confirmation requirement
- Validate plans through the Go CLI
- Simulate LOW-risk non-admin plans
- Dry-run LOW-risk non-admin plans
- Show CLI output in the log panel
- Show the local report directory or generated report path

## Risk gates

The frontend adapter and Tauri backend both treat these as blocking conditions for simulate and dry-run:

- `riskLevel` is `MEDIUM`, `HIGH`, or `DANGEROUS`
- any command risk is `MEDIUM`, `HIGH`, or `DANGEROUS`
- the plan has `requiresAdmin: true`
- any command has `requiresAdmin: true`

Validation may still be used to inspect a blocked plan. Execution-style operations remain disabled.

## Data boundaries

The GUI reads local example plans and writes no system configuration. Reports generated by CLI simulate or dry-run modes stay under the local reports directory. Logs and reports are generated artifacts and must not be committed unless they are sanitized examples.
