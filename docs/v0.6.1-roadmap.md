# v0.6.1 Roadmap

v0.6.1 extends the desktop GUI and Go CLI foundation with a tool catalog.

## Delivered

- Tool manifest schema
- Tool manifests for common AI/local-development tools
- Tool catalog examples
- Dry-run-only install-plan templates for agent and platform tools
- Safe Go CLI `tools` commands
- Desktop Tool Catalog tab and adapter scaffolding
- Validation script for catalog data and safe CLI previews

## Not delivered

- Real installation
- UAC/elevation
- PATH repair
- Proxy modification
- Package manager execution
- Agent bootstrap execution
- Tags, main merge, or GitHub Release

## v0.7.0 direction

The next step should focus on a Windows packaged installer preview while preserving catalog safety gates, manifest validation, and generated-artifact exclusions.
