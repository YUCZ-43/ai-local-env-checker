# v0.5.0 roadmap

v0.5.0 moves AI Local Environment Checker from documentation-only product architecture toward a real controlled execution engine.

## Included

- Go CLI plan commands for show, validate, dry-run, confirm-gated run, and simulate.
- Internal package boundaries for plan, policy, runner, report, detect, platform, and log utilities.
- Backward-compatible install-plan loading for string commands plus a richer command object model.
- Safe Windows demo install plan.
- Plan-runner report generation.
- Developer validation script for safe checks.

## Not included

- Full Tauri GUI.
- Automatic administrator elevation.
- Real package installation.
- PATH repair.
- System repair.
- GitHub Releases, tags, or publishing.

## v0.6.0 direction

The next MVP step is a Tauri GUI that calls the existing CLI/core engine to load, show, validate, and simulate install plans. The GUI should focus on review, risk display, confirmation UX, report viewing, and safe diagnostics before any broader execution capability is added.
