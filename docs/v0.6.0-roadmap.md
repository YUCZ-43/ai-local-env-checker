# v0.6.0 Roadmap

v0.6.0 adds the Tauri GUI MVP while preserving the safety posture from v0.5.0.

## Delivered in v0.6.0

- Tauri v2 desktop app skeleton under `apps/desktop-tauri/`
- TypeScript frontend with tabs for dashboard, environment check, install plan viewing, policy review, dry-run/simulate, logs, reports, and settings
- Frontend command adapters in `src/services/`
- Tauri backend commands for safe plan reads and safe CLI integration
- Plan risk and admin gates before simulate or dry-run
- Local report location display
- Safe validation script at `scripts/dev/check-v0.6.0-gui.ps1`
- Documentation for GUI usage and safety model

## Not delivered in v0.6.0

- Real installation
- Admin elevation
- `plan run --confirm`
- PATH repair
- Proxy setting modification
- Packaged Windows installer
- GitHub Release
- Tags

## v0.7.0 candidate direction

The next milestone should focus on a Windows packaged installer preview:

- Build and sign strategy for a Windows installer
- Bundled or discoverable Go CLI binary
- Installer-safe output locations
- More complete `doctor` output in the GUI
- Report preview inside the app
- Packaging validation that excludes logs, reports, target output, `node_modules`, generated binaries, secrets, and local machine paths
