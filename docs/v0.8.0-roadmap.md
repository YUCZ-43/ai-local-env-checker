# v0.8.0 Roadmap

v0.8.0 introduces the controlled automatic installation MVP.

## Goals

- Keep dry-run as the default mode.
- Require CLI `--confirm` for non-dry-run execution.
- Execute only LOW-risk allowlisted demo commands.
- Block admin-required, MEDIUM, HIGH, ADMIN_REQUIRED, and DANGEROUS execution.
- Write local audit logs for every controlled runner attempt.
- Generate reports with safety decisions and next recommended action.
- Show GUI confirmation state, risk review, dry-run status, and run result.

## Non-Goals

- No silent installation.
- No automatic UAC elevation.
- No real third-party installer execution.
- No PATH modification.
- No proxy modification.
- No global environment modification.
- No release publishing, tags, or GitHub Releases.

## v0.9.0 Direction

v0.9.0 should design a stricter per-tool installer approval flow:

- signed installer trust model
- per-command review and confirmation
- tool-specific rollback
- admin elevation UX without automatic UAC
- richer audit and report viewer
- package provenance checks
