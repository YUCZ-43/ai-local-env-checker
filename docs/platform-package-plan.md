# Platform Package Plan

This document describes the v0.9.0-alpha.1 package posture. It is a planning and release-accuracy guardrail, not an instruction to install dependencies or publish stable artifacts.

## Current alpha target

Windows is the only package target for v0.9.0-alpha.1. The generated Windows artifact, if validation succeeds, is for AI Local Environment Checker itself. It must not include third-party installers, silently install external tools, modify PATH, change proxy settings, modify global environment variables, or trigger UAC automatically.

## macOS package requirements

macOS packaging remains planned. Before claiming a macOS package exists, the project needs a validated Tauri macOS build path, app signing/notarization decisions, CLI sidecar bundling checks, local report/log location review, and user-facing documentation for security prompts.

## Linux package requirements

Linux packaging remains planned. Before claiming a Linux package exists, the project needs validated AppImage/deb/rpm or tarball strategy, CLI sidecar bundling checks, desktop entry review, local report/log location review, and distribution-specific dependency notes.

## Website download button accuracy

Website and README download links must point only to artifacts that actually exist in GitHub Releases or a controlled release location. Until a package is generated and uploaded, CTAs must use alpha-preview, source, docs, or GitHub wording instead of claiming a downloadable installer.

## Release artifact rules

Allowed release artifact for this alpha:

- A Windows package generated by this repository's Tauri app build, if validation passes.

Forbidden upload targets:

- Logs.
- Reports.
- `node_modules`.
- Raw `dist/` directories.
- Raw `target/` directories.
- Secrets.
- `.env` files.
- Private keys.
- Local machine paths.
- Unrelated generated files.

## Hosting routes

GitHub Pages is the preferred temporary static website preview route. Vercel and Cloudflare Pages can be used for preview deployments after owner confirmation, without production domains, DNS changes, paid resources, or production deployment.
