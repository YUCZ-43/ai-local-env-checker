# Supported Tools

v0.6.1 includes manifests for:

- Claude Code
- Codex CLI
- Hermes Agent
- OpenClaw
- Node.js
- Git
- Visual Studio Code
- WSL
- Docker
- Python
- Go
- Rust
- Tauri
- NSIS
- Microsoft Edge WebView2 Runtime

The status field shows whether each tool is supported, preview, template-only, or requires manual review. Agent tools are intentionally cautious because repository provenance, bootstrap scripts, and supply-chain behavior must be reviewed before installation.
