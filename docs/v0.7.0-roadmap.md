# v0.7.0 Roadmap

v0.7.0 focuses on a Windows packaged installer preview for AI Local Environment Checker itself.

## Goals

- Prepare Tauri desktop metadata for a Windows package preview.
- Document installer output handling and local-only generated artifacts.
- Document app config, logs, reports, and temporary file locations.
- Document the CLI discovery and future bundling strategy.
- Add a safe packaging validation script.

## Non-Goals

- No third-party installation.
- No automatic repair.
- No PATH modification.
- No proxy modification.
- No admin elevation.
- No release publishing.
- No generated installers committed to Git.
- No GitHub Releases or tags.

## Safety Status

The desktop app remains a safe preview. It can validate, simulate, and dry-run reviewed plans through the Go CLI adapter. It cannot perform real installation or call confirm execution.

## v0.8.0 Direction

v0.8.0 should focus on controlled automatic installation design:

- explicit user intent for every install action
- per-command confirmation
- signed installer strategy
- rollback and audit logging design
- clearer LOW/MEDIUM/HIGH/DANGEROUS policy gates
- admin elevation design without automatic UAC
