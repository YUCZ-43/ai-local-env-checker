# Backend and License Design

Backend, license, membership, and device authorization features are optional future capabilities.

## Offline-first rule

Local checks must work without a backend. The CLI and desktop app should remain useful offline.

## Future backend capabilities

- License validation
- Membership status
- Device activation
- Optional report upload
- Support ticket attachment
- Update metadata

## Privacy requirements

The product must ask before uploading diagnostic reports. Uploaded reports should be redacted or reviewed by the user before transmission.
