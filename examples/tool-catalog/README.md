# Tool Catalog Examples

These examples show the v0.6.1 tool manifest shape. They are safe data files only.

- `minimal-tool.example.json`: smallest useful detect-only tool entry
- `agent-tool.example.json`: cautious template-only agent tool entry
- `windows-cli-tool.example.json`: Windows CLI with a dry-run install-plan template

Do not put secrets, tokens, private repository URLs, local user paths, or fixed proxy ports in tool manifests.
